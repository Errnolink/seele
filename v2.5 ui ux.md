## 1. Overview & Capabilities

**WIERGISE** is a tactical media organization workstation designed for scanning, classifying, and organizing large volumes of image, video, and RAW files (25,000+ assets) at high performance.

### Core Capabilities
* **Streaming Virtualized Views**: Variable-height Masonry, Square Uniform Grid, Detailed List/Tape View, Folder Subdirectory Grid, and Split Grid+Inspector.
* **Hierarchical Volume Explorer**: Recursive directory tree with expand/collapse toggles, drag-and-drop file target support, and **Relative Size Capacity Bars** showing exact byte counts and payload percentages.
* **Tactical Classification Tags**: Interactive multi-tag classification system with item counts, inline tag creation (`+ NEW TAG`), multi-tag filtering, and batch tagging.
* **Session Audit Ledger**: Real-time logging of all file operations (Move, Rename, Purge, Star, Tag, Scan) with single-click Undo/Revert support and `.JSON` log export.
* **Full-Featured Inspector Dock**: EXIF technical details, camera optics, spatial GPS telemetry, color swatches, SHA-256 hash copy, and quick operations.
* **Cinematic Lightbox Viewer (`MediaViewer`)**: Fullscreen view with 1×–8× smooth zoom/pan, adjacent image preloading, filmstrip thumbnail jump, and video playback.
* **Authentic NERV Aesthetics**: True black void (`#000000`), signal orange (`#ff9830`), terminal green (`#50ff50`), wire cyan (`#20f0ff`), mechanically compressed display serif, and sharp chamfered polygon geometry.

## 4. Virtualization Engine (`src/lib/useVirtualMasonry.ts`)

`useVirtualMasonry` is an $O(n)$ single-pass masonry, grid, and list layout engine built for high-throughput scrolling.

### Key Logic
* **ResizeObserver**: Observes container size changes.
* **Shortest-Column Placement**: Items are assigned to whichever column currently has the smallest total height.
* **Viewport Window Slicing**: Calculates `topLimit = scrollTop - overscan` and `bottomLimit = scrollTop + containerHeight + overscan` to render only visible items (~40–120 items rendered even when 25,000+ files are present).
* **rAF Throttle**: Scroll events are throttled using `requestAnimationFrame` for 60–120 FPS performance.

## 7. Electron IPC Bridge Mapping

When integrating into Electron main process (`electron/main.ts`), map UI handlers to IPC invocations:

| Frontend UI Handler | Electron IPC Channel | Payload | Main Process Action |
|---|---|---|---|
| `handleConfirmMove` | `file:moveBatch` | `{ filePaths, destDir }` | Moves files safely via `fs.rename`, handles collision via `uniquePath()`. |
| `handleConfirmRename` | `file:rename` | `{ filePath, newName }` | Renames file on disk (rejecting path separators). |
| `handleTrashNodes` | `file:trashBatch` | `{ filePaths }` | Sends files to OS recycle bin using `shell.trashItem`. |
| `handleTriggerScan` | `file:startScan` | `{ rootPath }` | Initiates worker thread batch directory scanning & dimension probing. |
| `onSelectFolder` | `dialog:pickFolder` | `none` | Opens native OS directory picker dialog. |
